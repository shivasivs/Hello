# Hello World in C++

A simple C++ program that prints a welcome message to the terminal. This repository is part of my early practice with C++, compilation, and GitHub.

## What it does

- Prints “Hello World! Welcome to GitHub!”
- Demonstrates a basic C++ program structure
- Uses the iostream library for console output

## Run locally

1. Compile the program:

~~~bash
g++ hello.cpp -o hello
~~~

2. Run it:

~~~bash
./hello
~~~
